# 高三七班照片集 · Class 7 Memory

简洁的黑白班级相册，使用腾讯云 CloudBase 保存账号、照片信息、留言和图片文件。

**本次更新：2026-10-30「暗黑地牢云端联机」。** 保留照片集全部现有功能，新增同站游戏入口与独立 Socket.IO 云中继。协作者或 AI 开始修改前，请阅读 [AI 接手与持续更新指南](AI_HANDOFF.md)、[更新说明与文件索引](UPDATE_NOTES.md) 和 [AI 编辑指引](AGENTS.md)。后续 AI 每次完成或中断任务，都必须继续更新同一份 AI_HANDOFF.md。

## 功能

- 暗黑地牢：独立栏目按需加载，保留原版 v0.85.0 战斗、卡牌和音乐；Socket.IO 两人房间已使用云端中继，管理员电脑关机不影响新对局。房主结算、断线需重开，暂不接网站账号、积分和奖励。安装与迁移见 [游戏说明](docs/DUNGEON.md)。

- 每收藏20张不同照片奖励20积分，已有库存计入、每档一次；购买或抽卡后自动加分。每周大赛与这期神了最终前三每人每榜90积分，双榜180，从启用当周开始，周一00:00后访问时结算。

- 抽卡相机回放：成功后快门闪光、镜头推进，进入相机背屏显示本次照片、名称、稀有度和序号；单抽点击完成、十连点击逐张翻阅。支持结束演出/Escape、键盘翻阅和减少动态效果跳过；切换页面或账号时取消，不影响已入库结果。

- 抽卡栏目：单抽10积分、十连90积分，基础概率95.95/3/1/0.05；50抽保底传奇或保密，保密无保底，提前出传奇或保密重置传奇计数，跨天保留。直接入私人库存且不重复；卡池不足或无法兑现保底则整次不扣分。


- 管理员卡牌上传支持史诗/传奇/保密；保密照片不进入公开照片墙和共享相册，商城以0.05%初始权重抽取、40积分独占购买，也可从抽卡栏目获取，购买后仍仅库存可看。四类收藏成就显示在收藏页（黑暗往事拥有1张保密卡即可解锁，其他三类集齐），服务端持久保存，新增照片不收回。具体升级顺序与旧已购照片处理见最新更新说明。

- 深色镜头穿越开场：圆角黑白灰相机、语义化快门、六片弧形光圈循环压叠并旋转开启，约3.2秒连续推进并显露背后已渲染的真实首页；同标签页会话跳过可配置。没有跳转、重载、截图替身或首页节点重建；减少动态效果只淡出120ms。

- 每日卡片分普通95.95%、史诗3%、传奇1%、保密0.05%，传奇金色反光、史诗紫色反光、保密石墨黑暗红封签；库存按四种等级显示收藏进度，30/60/90张解锁三个收藏称号。详情、迁移和清单维护方式见 UPDATE_NOTES.md。

- 每日签到获得10积分，每连续7天额外30分；评论每条5分、每日最多50分，点赞照片/评论每项2分且同一登录账号对同一项只奖励一次。签到按北京时间计算，积分按登录账号独立保存，不自动合并关联账号的积分。
- 每日照片商城：每个账号每天固定随机五张、普通10、史诗20、传奇30积分，按北京时间零点换新；已买照片进入私人库存，可查看大图和说明，不影响公开相册。原作者移除原图后保留记录，图片不可查看。
- 评论照片表情：从个人库存按需选择一张，可单发或搭配文字/回复；缩略图可放大，兼容评论榜，公开不暴露库存记录编号。
- 满宽瀑布照片墙：电脑默认完整浏览，宽屏四列、较窄窗口三列，照片按完整比例排列，随页面向下浏览；可切换流动照片墙并记住选择。保留手机版排版、黑白主题、随机排列、暂停及 0.5×～3× 流速。
- 自动滚动使用浏览器原生合成动画，减少主线程逐帧写入；支持跟随高刷新率屏幕，实际帧率取决于设备、浏览器和负载，不保证恒定 120 帧。图片尺寸修正时保留现有节点。
- 独立账号和密码登录；昵称用于展示，照片归属绑定登录账号。相同昵称不会自动取得旧照片权限；可在账号设置中验证另一个账号的密码，关联双方现有和今后的照片、留言管理权限，退出重新登录仍保留。
- 关联账号可查看影响并解除：验证当前账号密码后，现有共享照片和留言保留给当前账号及其余关联账号；被移除账号失去管理权限，内容不删除。
- 多张上传，最多三个上传任务；可逐张填写说明、旋转，上传后也能修改说明。
- 超过 12 MB 的静态照片可自动压缩至 6 MB 以内，优先保留尺寸；较小照片原样上传。本地原图不变，可关闭压缩。
- 下载和设备支持的保存位置选择、公开留言、自己的照片单张/批量删除。
- 每条留言可回复与点赞；评论和照片一样每周重置点赞机会，公开只显示总数。被回复者登录后可在“回复我的”查看回复者的昵称与登录账号、回复内容和未读提醒。
- “这期神了”评论榜：本周、上周及总赞榜，突出前三名，标出来源照片，点击后定位原留言；按需加载、每页最多50条。
- 详情页黑白爱心点赞与取消，登录后跨设备保留状态；北京时间每周一重置机会，同一关联账号组每周对每张照片只计一赞。旧照片可再次点赞，历史总赞累计；解除关联后已有赞保留给剩余组。
- 手机照片详情将照片、名称与说明紧邻显示；长说明可点按展开，上传信息与管理操作折叠收纳，避免在照片和说明之间来回滚动。
- 使用须知在每个浏览器只自动提醒一次，页脚可重新查看。
- 照片总数与每页加载数量分开统计，超过 100 张仍显示相册实际总数；个人与上传者筛选使用相应总数，上传和删除后同步更新。

## 本地构建

需要 Node.js 20.19 或以上以及 npm：

```sh
npm ci
npm run build
npm run check
npm run audit:source
```

构建只生成文件，不登录云账号、不创建资源、不部署网站。生成目录已写入 .gitignore，无需提交重复构建文件。

## 当前运行方式

浏览器通过 /api/ 同源访问 HTTP 云函数；样式、脚本、字体由静态托管提供。后台使用私有 PostgreSQL schema 和私有图片存储，生成短期签名下载链接。

当前 cloudbaserc.json 中的环境 ID 和域名是公开配置标识，不是密钥。项目保留已有上海环境配置；迁往其他环境时按部署文档同步修改。

## 现有限制

- 压缩有损，已上传的压缩图无法靠增大文件恢复细节；原图应另行保留。
- 免费套餐的容量、流量、调用量和有效期以控制台为准；没有证明可以长期免费承载超过 10 GB 的原图。
- 当前后台使用180天服务端存储凭证，有效期至北京时间2027-04-16 13:36:55；需在到期前由环境所有者更新，不随源码分发。免费套餐的续期与凭证维护分别办理。
- 下载签名有效约一小时，长时间打开后可刷新；手机相册保存取决于系统和浏览器。
- 12 MB 是自动压缩的触发值，并非已确认的 CloudBase 上传上限。

### 点赞排行

照片墙工具栏新增“随机照片墙 / 点赞排行”，默认保留随机墙；选择会在本机记住。排行由 PostgreSQL 全局排序，以点赞数降序、上传时间降序和照片ID降序作为稳定次序，继续每页最多100张。支持个人照片与上传者筛选。关联账号按已有 canonical_owner 规则去重。

排行保留瀑布布局，使用完整浏览让名次保持稳定；切回随机墙恢复原来的流动/完整浏览偏好。小号名次标识只在排行出现，黑白主题同步。点赞动作只更新详情，不立即重排；点击“刷新”更新名次。并发点赞、上传期间的分页属于实时数据，刷新可重新同步整个排行。

沿用懒加载、图片并发队列、签名URL缓存，不下载全相册来排序，不增加每张照片的查询或定时轮询。现有点赞版本升级到此版本，只需构建并部署前后端，无需新增数据库迁移、云资源或凭证。

### 每周大赛

相册导航新增“每周大赛”，冠军居中突出、亚军季军分列两侧，照片名与本期票数在图下显示。剩余名次沿用分页瀑布墙。支持本周和上周，黑白主题及手机三列布局保留；大赛内隐藏大幅PHOTO标题和无关控件。

按北京时间每周一00:00至下周一00:00统计本周有效赞，同分依次按累计总赞、照片上传时间、ID排序。每周重置点赞机会，以前赞过的照片也可再次点赞；关联账号组每周对同一张照片只计一票。本周可取消和重赞，重复操作不累加，本周取消不删除以前各周的赞。原有总赞及已结算周榜保留。

私有photo_likes按照片、账号和周次记录有效赞；contest_weeks/contest_results保存结算成绩，photo_like_history保留旧版最早点赞记录。数据库在新一周首次访问大赛或首次点赞、关联变化、删除照片之前完成上一期结算，不需要外部定时任务、新云函数或付费调度。没有访问/操作时暂不执行结算，但下一次访问时返回的结果保持周末截止状态。删除照片仍会移除其历史展示；未产生有效赞时不会生成虚假前三名。

正常照片墙不额外请求大赛数据。前三名直接复用当前分页数据、不重复出现在下方瀑布墙；其余照片继续懒加载。点赞时不重排，刷新后更新榜单。

### 留言回复与点赞

打开照片详情，在留言下点击“回复”，写完后发送。回复会显示所针对的昵称和留言摘要；被回复者登录后从页面顶部的“回复我的”查看通知和回复者账号。通知只在站内显示，无需邮箱或微信。留言点赞支持取消，公开只显示总数；已关联的账号组每周给同一条留言只计一赞。

### 这期神了 · 评论榜

与“每周大赛”并列的相册导航，提供本周、上周和评论总赞榜。前三名卡片突出评论正文、作者、票数及来源照片，第四名起使用简洁列表；点击来源照片可打开并定位原评论，较早的评论也能直接查看。长留言可展开。

评论点赞按北京时间每周一00:00更新机会。旧评论每周可以重新点赞，本周取消仅影响本周；历史赞累计。每个关联账号组每周对同一条评论只计一赞。周榜同分依次按总赞、评论时间、ID排序，总赞榜按累计有效赞排序。原留言及原点赞保留，旧赞按原记录所在周计入；不会凭空把历史赞挪到本周。新功能开启前的历史周榜不补造。

上一期在下一周首次读取榜单、投票、关联账号变化或删除内容前补结算，不增加定时任务或付费资源。已结算榜保留成绩，删除原评论或来源照片后对应展示一并消失。周榜和总榜不公开点赞者身份。

正常照片墙不请求评论榜；切换栏目才读取，服务端排序分页，每页最多50条。照片缩略图按视口加载、最多两张并行下载；不全量加载评论或轮询榜单。点赞后即时更新按钮计数，名次在刷新时重排，避免阅读中跳动。原图文件仍用于来源缩略预览，首次出现的来源照片需要网络下载，实际速度取决于原图大小和连接。

### 签到与积分

顶栏签到按钮显示当日状态及个人积分。签到、断签和连续7天奖励均由数据库按北京时间判断；重复签到不重复加分。照片与评论依旧每周可以重新点赞，但同一登录账号对同一张照片/同一条评论最多领取一次点赞积分。取消点赞或删除评论不会自动扣回已经获得的积分，原有历史操作不自动补发积分。

点赞和奖励在同一数据库事务内完成；评论插入及加分通过现有参数化批处理事务一起提交。积分徽标随操作更新，退出/切换账号清理旧状态，不轮询积分。配置保存在私有 points_config，当前不提供前端管理配置的入口。

### 积分商城

相册导航新增“商城”，与照片墙、每周大赛、这期神了并列。商品按积分从低到高以卡片展示，标明价格与剩余库存；登录后点击两次确认兑换，立即扣分并在“我的兑换记录”查看。未登录可浏览货架，兑换时引导登录。

商品不在数据库中维护：协作者在根目录 `mall-goods/` 新增一个 JSON 文件即可上架，构建时校验格式并把清单同时写入前端页面和 HTTP 函数，价格与库存以服务端清单为准，前端无法改价。`enabled:false` 下架商品并保留历史兑换记录；限量商品的已兑数量按兑换记录计数。

兑换由数据库函数 `redeem_mall_item` 在单事务内完成：按账号串行加锁、限量商品再按商品加锁，余额行锁检查后扣分，扣分流水写入 points_ledger（负数），并插入 mall_redemptions 记录；任一步失败整体回滚，不会扣了分没记录或超卖库存。兑换响应回传新积分余额，顶栏徽标即时更新；切换或退出登录清空商城内的积分与记录显示。

已有环境升级：所有者登录官方 CLI 后先执行 `node scripts/apply-mall.cjs`，成功再部署前后端。只新增表和函数，迁移前后校验账号、照片、评论、点赞与积分数据不变。

## 调整镜头入口

编辑src/camera-intro-config.json：durationMs为总时长（毫秒，默认3200）；skipSession为false时每次加载都显示，true时同标签页成功进入后跳过。修改sessionKey可重置会话版本。欢迎文字在src/camera-intro.html的camera-intro-title与camera-intro-hint。运行npm run build后同步部署静态与HTTP函数。预览已进入的会话时关闭该标签页再新开；不要仅刷新期待重播。


### 已有照片设置卡牌等级

管理员登录后打开照片墙中的大图，在说明区域点“设置卡牌等级”，选普通/史诗/传奇/保密级并保存。原照片ID、文件、点赞、评论和收藏保留，无需再上传。已有环境新增apply-admin-photo-rarity.cjs迁移，详见最新更新说明。


### 管理员统一照片管理

顶栏“照片管理”将原卡牌上传与已有照片分级整合在一起。可搜索照片名/上传者，按四档等级筛选、分页查找和预览，直接选择等级保存；右上“上传卡牌”沿用原上传功能，支持返回管理列表。管理员专用，普通访问不会请求管理数据。新管理界面无需额外SQL迁移，依赖已有admin-photo-rarity增量。


### 保密级最终规则（覆盖本日早先公开规则）

保密卡仅在商城刷新，不在照片墙/共享相册展示，购买后也不转公开。管理员在照片管理可查看，当日抽到未售卡的账号和实际收藏者按权限看图；不能作为公开评论照片表情。已有环境最后应用apply-classified-private.cjs。新版本同时改为按需生成图片链接，避免100张并发签名触发429导致整页500；原图文件未压缩或移动。
