# 暗黑地牢 · Socket.IO 试接入

照片集导航新增「暗黑地牢」，同站路径 `/api/game/index.html`。游戏只在打开后加载；相册首页不加载游戏脚本、Socket.IO、图片或音轨。无数据库迁移，不接入网站账号、积分或收藏奖励。

## 文件与构建

- `src/dungeon-game/`：桌面原版 v0.85.0 拆分的界面、英雄/敌人、战斗引擎与素材，38 个独立素材。单机规则和卡牌保留。
- `src/dungeon-net.js`：保留原 `Net` 接口的 Socket.IO 客户端。
- `src/dungeon-config.json`：联机服务 HTTPS 地址、临时服务标记。
- `scripts/build-dungeon.cjs`：游戏构建及配置写入，由主构建调用。Socket.IO 客户端及许可证在源码内，不依赖 CDN 或外部兄弟工程。
- `scripts/import-dungeon.cjs`：显式重新导入原 HTML 的工具，包含 UI 同步修复。平时直接修改 `src/dungeon-game/`；重新导入会覆盖其中同名源文件，只能在确认保留后使用。
- `src/dungeon-service/`：独立 Node.js 中继模板，Socket.IO `/dungeon` namespace，两人房间、角色校验、限流、消息上限；不部署到照片 API 进程。

大型图片和音乐由原站已有静态托管域名提供，HTTP函数只打包轻量页面和脚本，避免超过CLI直接ZIP上传的1.5MB限制。不新建COS桶或调整套餐。

主项目执行 `npm run build`，然后 `node scripts/check-project.cjs`。本分发包提供 `npm run check` 与 `npm run audit:source`。

## 发布与后续

网站入口和游戏文件需更新现有 CloudBase HTTP 函数及静态资源。无需执行任何 SQL、初始化、积分补偿或账号脚本。`src/server.ts` 只追加游戏图片/音轨 MIME 类型。

正式长期联机应把 `src/dungeon-service/` 部署到经确认可承载长连接/房间状态的环境。该模板是内存房间，不能不加共享状态就任意多实例扩容。费用、地区、实例并发和额度必须另行核对，不应直接把服务塞进现有短超时照片函数。

更换联机地址后修改 `src/dungeon-config.json` 并重新构建网站。新域名按需加到服务端 `GAME_ORIGINS`，WebSocket 跨域仍不应携带相册 Cookie。
